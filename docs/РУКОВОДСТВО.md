# Руководство пользователя

«Веб отчётность» — учёт аварий на базовых станциях для дежурных ЦОУ, инженеров ТЦ и руководства. Работает в браузере (Chrome 75 и новее), рассчитана на экраны Full HD. Скриншоты всех экранов — в [README](../README.md#где-что-находится).

## Дежурный

### Внести аварию

Вкладка «Аварии», форма «Новая авария» — вверху страницы.

1. **Сетевой элемент.** Начните вводить код или название объекта (`GT_VJW`, `Солнечный`) и выберите его из подсказки. Направление, ТЦ, тип сети, оборудование и количество БС подставятся сами.
2. **Тип и описание.** После выбора типа поле «Описание» подсказывает частые формулировки: для ЭЛ — «Аварийное отключение промсети», для RBS — «Аппаратная неисправность».
3. **Начало** — календарь или «Сейчас». Даты в будущем недопустимы.
4. **Окончание** — «НВ», если авария продолжается.
5. **Уведомление (кому)** — кого известили вы сами. Быстрые вставки: «+ время сейчас», «+ по телефону», «+ при получении сводки». Письма по правилам уходят сами.
6. **Сохранить.** Для массовой аварии на нескольких БС — «Сохранить и внести похожую».

Длительность и общий простой (перерыв × количество БС; сектор «С» — как одна БС) считаются сами. Черновик хранится в браузере. Сохранить можно и сочетанием Ctrl + Enter.

### Табло открытых аварий

Табло — под формой.
- Сверху — аварии за последние сутки, новые первыми; таймер идёт в реальном времени.
- «Длятся больше суток» — свёрнутые переходящие аварии, раскрываются кнопкой «Показать».
- Отбор по ТЦ — в заголовке табло.
- У аварий по электропитанию — ориентировочный прогноз по паспортной автономности АКБ. Реальная ёмкость батарей со временем падает, поэтому при «разряжена» проверьте, работает ли БС.
- «Закрыть» — указать время окончания, по умолчанию стоит текущее.

## Инженер и руководство

### Отчётность

- **Период:** календарь или кнопки «Сегодня», «Вчера», «7 дней», «30 дней», «Этот месяц», «Прошлый месяц».
- **«Какие аварии учитывать»:** «начавшиеся в периоде» или «действовавшие» — тогда в отчёт попадают и аварии, открытые раньше.
- **Фильтры:** направление, ТЦ, категория, тип сети, тип аварии, состояние. Поиск — по PW/NTT, объекту и описаниям.

Выгрузки:
- **CSV** — открывается в Excel без настройки. Разделитель на выбор: `;`, `,`, табуляция или `|`. Значения с разделителем, кавычками или переносами строк заключаются в кавычки, поэтому столбцы не съезжают.
- **Excel как сводка** — лист «Аварии на сети СС» в формате сводки ЦОУ.
- **Печать** — текущая страница отчёта.

Нажатие на строку открывает карточку аварии. В карточке — история изменений (кто, когда, что было и что стало) и отправленные уведомления.

### Статистика

- Итоги за период и сравнение с прошлым таким же периодом.
- Разбивки по типам, направлениям, ТЦ и категориям.
- Матрица «ТЦ × тип аварии», повторяющиеся аварии на одной БС, топ по простою.

Нажатие на столбец или ячейку открывает отчёт с этим отбором.

### Сводка за смену

Смена — с 08:00 до 08:00. Если есть правило со сводкой, в заданное время приходит письмо. В нём все аварии, которые действовали в эти сутки, в том числе начавшиеся раньше, а также разбивка по типам и ТЦ, открытые сейчас и самые долгие.

### Инвентарь БС

- Объекты в формате «код — название».
- Для каждого объекта: ТЦ, оборудование, автономность АКБ по паспорту, ДГУ, число аварий за 90 дней.
- В карточке объекта — его последние аварии и кнопка «Внести аварию по этой БС».

## Администратор

- **Пользователи** — создание, роль, отключение, новый пароль.
- **Справочники** — направления, ТЦ, типы сети и аварий с расшифровками.
  - Переименование значения обновляет старые аварии.
  - Скрытое значение пропадает из формы, но остаётся в отчётах.
- **Инвентарь** — правка объектов, загрузка из CSV (выгрузка Site Info, Excel или столбцы сводки), выгрузка.
- **Загрузить сводку** (вкладка «Отчётность») — перенос действующей сводки ЦОУ из .xlsx. Сначала программа показывает, что будет сделано. Повторная загрузка не создаёт дублей.
- **Уведомления:**
  - почтовый сервер компании и разрешённые домены — письма уходят только на внутренние адреса;
  - правила: кому и о каких авариях сообщать — при внесении, при закрытии, «открыта дольше N часов», сводка за смену в заданное время;
  - журнал сообщений с повторной отправкой.
- **Корзина** — удалённые аварии.
  - «Восстановить» возвращает аварию с прежним номером.
  - «Удалить навсегда» стирает её окончательно; копия остаётся в журнале.
- **API** — ключи для внешних систем («только чтение» или «чтение и запись»), документация по ссылке «Документация API».
- **Журнал действий** — входы, изменения аварий, настроек, справочников, загрузки, удаления и восстановления, действия по ключам API.
