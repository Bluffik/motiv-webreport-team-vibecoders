# Изменения

## 1.0.0 — 15.11.2026

Первая версия: кейс №02 «Веб отчётность», ООО «Екатеринбург 2000» (Мотив).

**Учёт аварий**
- Все 19 полей ТЗ, справочники в БД, автоматический расчёт длительности и общего простоя (сектор «С» — как 1 БС).
- Форма «Новая авария» сверху, под ней табло открытых аварий: свежие сверху, переходящие (больше суток) свёрнуты, отбор по ТЦ, ориентировочный прогноз по АКБ.
- Инвентарь БС в формате «код — название», поиск объекта в форме, подстановка ТЦ, направления, оборудования.
- Подсказки описаний по типу аварии и исполнителей по ТЦ; быстрые вставки «время», «по телефону», «при получении сводки».
- Удаление в корзину с восстановлением прежнего номера.

**Отчётность**
- Отчёт за период с фильтрами и итогами.
- Выгрузка CSV с экранированием по RFC 4180 и выбором разделителя: `;`, `,`, табуляция, `|`.
- Excel в формате сводки ЦОУ (лист «Аварии на сети СС»), загрузка действующей сводки .xlsx без дублей.
- Статистика: сравнение с прошлым периодом, разбивки, матрица «ТЦ × тип», повторы на одной БС, топ по простою.

**Уведомления**
- E-mail через почтовый сервер компании, только на внутренние адреса (разрешённые домены).
- Правила: внесение, закрытие, эскалация затянувшихся, сводка за смену 08:00–08:00 со всеми действовавшими авариями.
- Подключение к почте в интерфейсе с проверкой; пароль хранится зашифрованным.

**Интеграция и эксплуатация**
- API с ключами доступа (чтение / чтение и запись), документация `/api/docs`, OpenAPI.
- Роли администратор, дежурный, инженер; журнал действий и история каждой аварии.
- Docker Compose v1/v2, комплект с образами для сервера без Docker Hub, HTTPS (свой сертификат или балансировщик), ночные резервные копии.
- Совместимость с Chrome 75, рабочие места Full HD.
